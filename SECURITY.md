# Security policy

DeckMate is an experimental prototype and has not undergone an independent
security review. Do not rely on it as the sole means of protecting or repairing
your device.

## Reporting a vulnerability

Please do not publish secrets, personal logs, or a working exploit in a public
issue. Report security concerns privately through
[GitHub's vulnerability reporting for this repository](https://github.com/lokaovida-eng/deckmate-steam-deck/security/advisories/new)
when available. If private reporting is unavailable, contact the maintainer
through the public GitHub profile and ask for a private channel.

## User data and actions

Prompts and related information are sent to GitHub Copilot. Treat logs and
diagnostic output as potentially sensitive. Inspect every requested system
action before approving it; never approve an action you do not understand.
